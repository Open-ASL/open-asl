# Security

If you find a security problem in Open ASL, for example a way to read another player's hidden units, to
submit a move the server should refuse, or to reach data the security rules should protect, please report it
privately rather than in a public issue.

Use GitHub's **private vulnerability reporting**: the *Security* tab of this repository, then *Report a
vulnerability*. Describe what you found, how to reproduce it, and what it affects.

You will get an answer within a week. Please give us a reasonable time to fix the problem before you talk
about it in public. Thank you for helping keep players' games fair.
